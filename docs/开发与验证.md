# 开发与验证

普通使用者从 [安装教程](安装到iPhone.md) 开始，本页供维护者复现检查。

## 工程说明

- 原生 SwiftUI，iPhone，最低 iOS 17；无第三方 Swift 包依赖。
- `EnglishPractice`：App 运行方案。
- `EnglishPracticeChecks`：模拟器界面检查方案。
- Team 已留空，Bundle Identifier 为 `org.example.englishpractice` 示例值；真机安装必须由使用者设置唯一标识和自己的 Team。
- 原创内置课程不携带虚构原声时间；结构示例 JSON 的演示时间仅用于导入测试。

## 可复现检查

在整套仓库根目录运行；Python 需安装 skill 的 `requirements.txt`：

```bash
python tests/run_checks.py
xcodebuild -project app/EnglishPractice.xcodeproj -scheme EnglishPractice \
  -configuration Debug -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath /tmp/english-practice-build CODE_SIGNING_ALLOWED=NO build
```

界面测试请在 Xcode 选择 EnglishPracticeChecks、选择一个已安装的 iPhone 模拟器，再执行 Product → Test。测试要求当前测试 App 仍保留“每日英语练习”示例；建议使用独立模拟器。若已经手动删除示例，请换干净的测试环境，不删除自己的资料来凑测试条件。
