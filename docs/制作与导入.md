# 从视频到手机练习

## 先体验内置示例

首次打开 App 会显示“每日英语练习”：两段原创短句、三个核心要点、两道完整原句题。它用于体验阅读、录音和抽题，没有配套视频，不提供虚构的原声。

skill 中的 `examples/demo-lesson.json` 是另一种格式演示，带有明确标记的虚构时间和指纹，只用于脚本测试，不能拿去匹配自己的视频。

## 安装英语学习 skill

将 `skills/english-learning` 整个文件夹放到自己的 Codex skills 目录，保留文件夹名称。已有同名 skill 时先备份或比较，不直接覆盖。详细位置、依赖及操作见 [skill 说明](../skills/english-learning/README.md)。

它是一套由助手执行的制作流程，不是一个独立转写软件；第一次使用需要准备 Python、识别模型及文档预览工具，可把说明交给 Codex 协助检查。它默认在本机处理视频；下载模型需要网络。

## 让 skill 制作资料

给 Codex 提供有权使用的英语视频，并说明：

> 请调用英语学习 skill，处理这个视频，制作供英语随身练使用的双语 Word。单词、词组和句式都要关联原文整个句子，并包含真实音频时间。完成全页排版和 App 导入校验。App 源代码在分享包的 app/EnglishPractice 目录。

把最后的源代码路径替换成实际位置，或直接让助手定位分享包。

成品 Word 包括双语原稿、核心要点、完整原句、时间索引及供 App 使用的内嵌数据。保留最初的同一份原视频，不重新剪辑、转码或压缩后替换。

## 把文件放到 iPhone

将最终 `.docx` 和原 `.MP4` 通过 AirDrop 或 iCloud Drive 等方式放到 iPhone 的“文件”App。传输后保留原字节；不要用导出照片视频的方式重新编码。

App 支持标准、未加密的 `.docx`（20 MB以内）。视频当前限制20分钟、600 MB。更长素材需先裁成适当片段，再从该片段重新制作学习稿；不要用旧稿匹配新视频。

## 导入并练习

1. 打开“英语随身练”，点击右上角“＋”，选择从文件导入 Word。
2. 选生成的配套 Word，点击“下一步”，核对标题、分段和学习要点。
3. 点击“添加对应视频（可稍后添加）”，从“文件”中选同一份原视频。
4. 核对原声，试听句首句尾；必要时调整切点，点击“保存原声设置”。
5. 返回导入预览，点击“完成导入”。
6. “原文阅读”的朗读播放整段；核心要点或整句抽题的“朗读原文”播放该要点对应的完整原句。

也可以先导入文稿，以后从文稿页添加视频。普通 Word/粘贴文稿可以用于基础阅读，但未必具备完整要点和原声时间；要获得本套完整功能，请使用 skill 成品。

## 遇到不匹配

- 视频指纹不同：确认选的是制作学习稿时的同一文件，不是剪辑或转码后的副本。
- 原声没有开始/结束时间：确认 Word 保留了内嵌数据；不要用复制正文到新 Word 的方式代替原文件。
- 切点不理想：试听并微调，或让 skill 重查对应句子。
- 某个要点不是完整原句：请修订源数据并重新生成稿件，不把零散词组当成整句原声。

App 不会在手机上重新识别视频或自动纠正英语；语音识别、翻译与时间准备由 skill 完成。
