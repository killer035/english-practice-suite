# 制作与校验要求

## 参考结构

默认版式由 scripts/build_word.py 生成：A4，黑色文字，Noto Sans CJK SC（须自行安装并检查音标覆盖；可通过 --font 更换）；主标题24pt、一级17pt、二级13pt、正文11pt，正文行距1.18，表格10pt；浅蓝表头、细灰边框，页眉“英语学习 · 视频配套学习材料”、页码。表格重复表头、行不跨页。按内容调整分页，不能固定复用参考的页数。

顺序：标题；数字段落编号及每段英文/中文；核心学习要点（单词表、词组表、句式及例句）；原文表达提示、音标说明；音频时间索引（视频文件名、段落主题和起止时间表、句子起止时间及英文表）。正文区不得插入说明、时间标签或要点，避免 App 将它们误认成正文。时间索引集中在后部，保持默认结构。

## 识别和对齐

- 先查缓存指纹、工具和模型。原视频仅本地处理；如必须使用外部服务且需要上传视频，先明确告知并取得用户授权。缺少模型可先复用已缓存模型，无法运行时如实说明，不能虚构结果。
- 优先读取内嵌字幕；烧录字幕用帧 OCR。scripts/ocr_video.swift 默认0.5秒采样，可按字幕变化密度调整并对遗漏区间加密，保留文字位置和置信度，排除水印/用户名。
- 本地 ASR 使用逐词时间；默认识别后端为 faster-whisper small.en CPU int8。模型不是质量保证，对含糊处可换更强模型或复听局部；不必把长视频每轮全部重跑。识别日志/原始字幕/差异分开缓存。
- 英文保留原话（含口语表达和必要衔接词），规范化大小写标点；错误用法的改善建议单列，不润色后冒充原话。专有名词、否定、数字和词形须重点核对。
- 中文段落与句子按含义对应，不按字幕行数或字数机械对齐。无中文字幕时生成忠实译文，不声称“视频中文原稿”。
- 句子以完整意义为单位；缩写、引号内句号不要错误断句。跨句复合例句可作为一个完整练习单元，但须覆盖连续原声。不凭空生成新句当原句。
- 用校正文本对齐逐词音频，首词末词都需支持；字幕时间仅辅助定位。可加很短的前后缓冲，但不能切到邻句、前后段重叠或超出音轨。每次音频裁剪都加回视频时间轴偏移。
- 仅在需要 App 兼容时，对重复原句用相邻原文扩展成唯一的连续练习单元，同时更新所有关联；不能编造上下文或删除视频内容。通用 Word 不要求原句唯一；App 以规范化英文查找片段，多个时间的相同文本会被拒绝。
- 抽查清晰句，重点复核每个异常边界和差异；交付说明区分自动校验、局部试听与完整人工试听。不能用“100%匹配”掩盖未核实边界。

## 学习要点

选择本篇有学习价值且确实出现的词、词组和句式。单词以词典原形列出，例句保留实际词形。提供一致的宽式音标（参考为美式）；不确定的音标/词性/用法查可靠词典。句式可以抽象成结构，但例句必须逐字取自整理后的原文。每项中文释义与完整句子译文分开。

## 交付门槛

1. 双语语义、数字、否定、词性音标和例句均校对。
2. 全部段落与句子时间有依据；各要点引用真实 sentenceID，不随机模糊关联。
3. validate_package.py 检查通过，包括实际音轨范围。结构校验不能替代听音语义检查。
4. 用 scripts/render_word.py 或可用 Documents 渲染器渲染每页（macOS 优先经 scripts/render_word.py 包装，以防打包渲染器找不到系统中文字体），检查表格不截断、IPA无缺字、标题不孤行、无大块意外空白。必要时调整 pageBreakBeforeParagraphs，重新生成并检查。
5. 最终 Word 再做通用检查；App 模式另做导入检查，避免编辑工具移除 customXml。只交付最终 Word；视频保持原文件。
