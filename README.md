# 英语随身练：视频学习 skill + iPhone App

## 让喜欢的视频，成为随身练习的素材

提供喜欢的英语视频 → 用 skill 生成学习稿 → 将学习稿和原视频导入 App → 在 iPhone 上阅读、练习口语、听原声、录音回听和随机抽题。

把收藏的视频用起来，让学过的英语有机会真正说出口。


## 可以做什么

这套工具由两部分组成：**英语学习 skill** 和 **英语随身练 App**。

### 1. 英语学习 skill：把视频变成学习材料

- **中英分段原稿**：把你喜欢的英语视频按内容和语义划分段落，整理各段的英文原话及对应中文译文。
- **核心学习要点**：提炼视频中的单词、词组和句式，并匹配它们所在的完整原句及译文。
- **原声时间定位**：识别各段及完整原句的起止时间，供“英语随身练 App”定位播放视频原声。
- **输出 Word 文档**：将上述内容整理成一份可阅读、可导入 App 的学习稿。

### 2. 英语随身练 App：把学习材料变成开口练习

导入原视频和 skill 生成的学习稿后，你可以：

- **逐段对照练习**：查看划分好的中英文段落，尝试用英语表达，并直接听对应段落的视频原声。
- **强化核心要点**：查看单词、词组和句式，通过随机整句抽题巩固表达，并听这些要点所在的完整原句。
- **拓展话题表达**：结合文稿内容和内置话题提示，练习表达观点、说明理由和分享自己的经历。
- **录音与回听**：录下自己的英语表达，回听检查，反复练习。


## 第一次使用，从这里开始

1. 下载并解压整个分享包。如果从 GitHub 下载，选择 Code → Download ZIP。
2. 准备一台 **Mac、一部 iOS 17 或以上的 iPhone、可传输数据的连接线及自己的 Apple 账号**。
3. 按 [Xcode 安装教程](docs/安装到iPhone.md) 将 App 安装到手机。不需要修改功能代码，但需要按教程选择自己的签名账号。
4. 打开 App 中的“每日英语练习”，先体验阅读、整句抽题及录音。它是原创示例，不附视频原声。
5. 按 [制作与导入学习资料](docs/制作与导入.md) 添加你自己的视频课程。

**这是一份源码分享包，不是直接在手机上点开安装的文件。** 安装 App 使用自己的 Xcode；制作新资料需要能运行 skill 的 Codex 环境及其依赖。若已有配套 Word 和同一原视频，可以直接导入，无需自己运行 skill。

## 使用边界

个人签名可能需要定期连接 Xcode 重新运行；遇到不可用，按安装教程恢复，先备份，不先删除 App。不同 Xcode/iOS 版本的菜单可能略有区别。

App 未包含作者的个人账号、私人学习视频、学习记录或签名证书；没有内置云端 AI 服务、广告或统计 SDK。原声定位依赖 skill 输出的时间数据，自动检查不能替代试听。系统合成朗读（若使用）与视频原声不是同一功能。

开源准备版基于 0.6.0，并包含核心要点直接展示、整句原声播放的后续改动。验证范围见 [开发与验证](docs/开发与验证.md)。
